# CLAUDE.md - anthemic-hub

## What this repo is

Static site for `anthemic-developments.com`. No build step, no framework — plain HTML/CSS/JS + PHP admin in Docker on Droplet.

## Key facts

- **No build step.** Hand-written HTML/CSS/JS. Never add bundler or framework.
- **Two repos:** `anthemic-hub` = site content; `anthemic-ops` (sibling) = nginx. Nginx changes → anthemic-ops.
- **Deploy:** push `main` → GitHub Actions → rsync `/home/deploy/incoming-hub/` → `sudo /usr/local/bin/anthemic-hub-deploy-apply.sh <incoming>`. Site/contact/mmd updates are automatic. The apply script itself does **not** self-update from `incoming-hub/` (manual root `install` after review). See README **Deploy** + `.github/workflows/deploy.yml`.
- **Preserved across deploys** (git = seed only): `gigs/gigs.json`, `content/hub.json`, `assets/gallery/manifest.json`.

## Admin panel

- URL: `/gigs/admin/`
- Auth: nginx `auth_basic` (htpasswd on Droplet) + PHP bcrypt (Docker env var)
- Runs: `php:8.2-cli` container, port `127.0.0.1:9001`, volume `/var/www/anthemic-hub:/app`
- Entry: `/app/gigs/admin/index.php` with `-c /app/gigs/admin/php.ini`
- Tabs: Gig calendar · Site content · Gallery
- CSRF token in session on all POST

## Dynamic content (fetched client-side)

| File | What it drives |
|------|---------------|
| `/gigs/gigs.json` | Gig calendar (`gigs/index.html`) |
| `/content/hub.json` | Hub bio, instruments, projects |
| `/assets/gallery/manifest.json` | Photo gallery on hub landing |

Fetches have HTML fallback — page works without JS.

## File paths inside the PHP container

Docker mounts `/var/www/anthemic-hub` as `/app`. PHP at `/app/gigs/admin/index.php` → `__DIR__` = `/app/gigs/admin`.

| PHP `$var` | Resolves to |
|------------|-------------|
| `$gigsPath` | `/app/gigs/gigs.json` |
| `$contentPath` | `/app/content/hub.json` |
| `$galleryPath` | `/app/assets/gallery` |

## Gallery manifest schema

Auto-generated by admin on upload/delete. Do not edit manually.

```json
{ "images": ["filename.jpg", "filename2.png"] }
```

## Interest filter

Cards: `data-interests="music gigs teaching creative work community personal"`. Hub sections have `data-interests` too. JS in `index.html` sorts matches to top on dropdown change. `sectionMatchCount()` checks section + card attrs.

## nginx (anthemic-ops)

`/gigs/admin/` proxies to `127.0.0.1:9001` with `auth_basic`. No PHP in main nginx — all PHP via container proxy.

## Thinkers maps (philosophy essays)

Essays + timeline + currents + fiction: `grounding-the-unconscious.html`, `genealogies-of-desire.html`, `constellations-of-history.html`, `technics-and-time.html`, `map-of-maps.html`, `map-of-maps-currents.html`, `fiction-of-the-maps.html`.

**Intros (always):** introduce the argument, not the identity slot. Gender/race/nation only when they are the thesis — never “woman hinge”, diversity annex, named-women census, or “non-European entry point.” Who belongs is who changes the quarrel of that current; place them on the map that asks it, not a segregated add-on. Same for `fiction-of-the-maps.html` writer picks. See `.cursor/rules/thinkers-maps-bias.mdc`.
